# Template 10 · Honest Demo Script and Weekly Status Report

Curriculum links: Turns 113 (stakeholder communication and demos), 110 (ROI), 114 (adoption).

## Part A: Demo script (15 minutes)

| Min | Segment | What you show | What you say |
|---|---|---|---|
| 0–2 | The problem | Baseline numbers from discovery | "Today X takes Y minutes at Z% error." |
| 2–8 | Happy path | 2 real-looking cases end to end, with evidence and citations visible | Tie each screen to a user step it removes. |
| 8–10 | **A visible failure** | A case the system gets wrong or escalates | "Here is how it fails, and how the design catches it." |
| 10–12 | Numbers | Eval-set results with confidence intervals; cost per task | Quote the frozen test set only, never cherry-picked runs. |
| 12–15 | Decision | What you need from them (access, approvals, budget) and by when | Offer options with consequences. |

Rules: use no live data without approval, no fake metrics, and state the limits out loud.

## Part B: Weekly status report (one page)

- **Status:** GREEN / AMBER / RED, and the reason in one line
- **Done this week:** …
- **Next week:** …
- **Metrics:** golden-set score (trend), pass^k, cost per task, adoption funnel (pilot)
- **Risks** (owner, date, mitigation): …
- **Decisions needed** (by whom, by when): …
- **Asks:** access, SMEs, approvals
